Reflection Tab

Project Function: This project is a 4x4 memory matching game where players flip two cards at a time, match character pairs, and try to clear the board before running out of lives.

Design Choices: I used a pink gradient background, animated bubble effects, character-based card art, alternating card-back designs, and HUD elements (moves, hearts, and progress bar) to make the game playful and readable. The background was loosely based on the cover of one of the animes featured in the game.

Concepts Used: I used DOM selection and updates, event listeners, arrays/objects for card data, shuffle logic with randomization, game state variables, conditional matching logic, timed resets with setTimeout, CSS transforms for card flips, and dynamic audio playback tied to user interaction like in the Jukebox project.
