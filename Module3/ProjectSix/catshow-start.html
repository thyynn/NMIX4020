Character Select: pick your cat class to enter the arena.

Explaination

A main Vue instance controls which breed is selected through buttons that update the whichcat variable. Based on that value, Vue conditionally displays a reusable cat-show; component using v-if. The component receives a breed prop from the parent, which tells it which breed's data to request. Inside the component, reactive data properties store images, breed info, and rating stats. When the component is created, or when the breed prop changes, it automatically calls loadNextImage() to fetch fresh data. loadNextImage() uses Axios to request ten images for the breed, stores them in an array, then makes a second request to get detailed breed information. Those values are saved into the component's data, and Vue instantly updates the template. The slideshow() function cycles through the image array by updating an index and setting the current image; the img tag is bound to image.url, so each click of “Next Image” shows the next picture. The template displays all text with {{ }} bindings and uses dynamic style bindings to turn 1-5 ratings into visual bars, showing how Vue links data, logic, and HTML together without reloading the page.
